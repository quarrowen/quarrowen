# Quarrowen

A voxel game where **the server decides the game**. One app plays any server's world, because the client
ships no content of its own: it downloads the blocks, models, textures, sounds and rules from whichever
server it joins. A sandbox, an island to survive on, a story to play through — same client, different
server.

It was built for one family's children, and it is free for yours.

**[Download for Mac](https://quarrowen.com)** — signed and notarized, so it opens by double-clicking, and
it keeps itself up to date after that.

## What comes with it

- **Hearthhold** — a valley whose light went out. Light the hearth, see the night out, find the people who
  scattered into the hills and build them somewhere to live.
- **Vanilla** — survival and creative building on generated terrain: caves, ores, weather, animals,
  monsters, a boss, and a guidebook that fills in as you go.
- **One Block** and **Sky Islands** — two ways of starting from nothing.
- Add-ons for magic, machines and a trading guild.

Every one of those is a mod. None of it is built into the client, which is the whole point: your server
can load something else entirely, and everyone who joins gets it automatically.

## Built with Claude Code

**Every line of this engine was written with [Claude Code](https://claude.com/claude-code), from an empty
folder** — the voxel renderer and its Rust mesher, the authoritative server and its network protocol, mob
AI and pathfinding, the mod API and its sandbox, world generation, the tests and the tooling. No engine
template and no asset packs: the textures, models and sounds are all generated by scripts in `tools/`.

It is also how the game is developed day to day. Family playtest feedback goes in; features, fixes and
tests come out. [CLAUDE.md](CLAUDE.md) is the brief it works from, and [PROGRESS.md](PROGRESS.md) is the
running record of what was decided and why — including the bugs, which are mostly more interesting than
the features.
