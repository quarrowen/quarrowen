    Playing Quarrowen

    This is for the person holding the mouse. If you are setting up a server for the family, see hosting.md; if you want to make things for it, see modding.md.

    Getting in

    Download from quarrowen.com, drag Quarrowen into Applications, and open it. It is signed and notarized, so it opens by double-clicking. It checks for a new version when the menu opens and offers it; nothing downloads from a game server except that server's own content.

    Type the name you want in Playing as at the bottom left. The first person to use a name on a server keeps it, so pick the one you mean to keep.

    Then either:

    • Multiplayer → LAN finds servers on your home network by themselves.
    • Multiplayer with a hub address (Settings → Network) lists the servers that hub knows, and short invite codes like QW-3BJ-46N work there too.
    • Play makes a world on this computer, with whichever game you choose.

    Controls
    Move W A S D, Space to jump, Shift to crouch, Ctrl to sprint
    Look mouse
    Break / place left / right mouse
    Hotbar 1–9, or the mouse wheel
    Inventory E
    Crafting C at a table, or right-click the table
    Guidebook G
    Map M (the wheel zooms it)
    Chat and commands T, then /help
    Block palette (creative) B
    Fly (creative) double-tap Space

    Every key can be changed in Settings → Controls.

    How it looks

    Settings → Graphics has four presets, and F4 cycles them:
    Fast For the oldest machines. Renders at 70% and upscales; no swaying plants, no fancy water.
    Balanced The default. Swaying plants, fancy water, bloom and colour grading.
    Fancy Balanced at full resolution, with anti-aliasing.
    Realistic Real sunlight and shadow, scattered sky, reflections in water, surface relief and aerial haze.

    Realistic asks a lot of the machine. On a base M1 Air it runs at around 25–29 fps, which is playable but not smooth; on anything with a discrete graphics card it is comfortable. Every part of it can be switched off on its own if you want most of the look for more of the speed — Surface relief is the one to try first, since it does the most work per pixel.

    Changing a single setting moves the preset to "Custom", which is only a label: nothing is lost.

    Your first hour

    A guided game leads you: it sets out the first few things to do, in an order that makes sense, and a tracker at the left of the screen says what is next. Follow that when it is there.

    Otherwise, the short version of survival:

    1. Punch a tree. Logs become planks, planks become sticks and a crafting table.
    2. Make a wooden pickaxe, then mine stone, then make a stone one. Each tier opens the next.
    3. Make a torch before dark. Something that burns, sitting on top of a stick.
    4. Sleep in a bed to skip the night, or stay somewhere lit.

    Press G at any point. The guidebook fills in as you play and is searchable; a page appears when you first meet the thing it is about.

    Crafting, and discovering recipes

    Some recipes you simply know. Others you work out, and that is deliberate — finding one out for yourself is the good bit.

    Open a crafting table and use the Experiment tab: put items you are holding into the grid and try them. Nothing is used up by trying. If you are close, it says so — "these belong together, but not arranged like this" means you have the right things in the wrong places. Some recipes care about arrangement; most do not.

    The book tab lists what you know, with a search. R on an item asks "how do I make this?" and U asks "what is this used in?".

    Plenty of things are never made. For those, the same panel says where they come from instead — which block drops them, which creature, which chest, or how deep in the ground to dig. If a game has written a note for something nothing could work out on its own, that shows up there too.

    Dying

    You drop a grave holding your things. Only you can open it, it is marked on your map, and it waits for you. /back returns you to where you died.

    Useful commands

    Type T, then:
    /help everything you can type
    /spawn back to the start
    /sethome, /home set and return to a home
    /milestones what you have done, and what is left
    /guide open the guidebook
    /server <name> travel to another of this server's worlds

    In Hearthhold: /charter for what the valley needs next, /valley for which way it is, and /bramble for where she has got to.

    If something goes wrong

    Settings → Files lists every folder the game uses on your computer, with a button that opens it — the logs are there, which is the first thing to look at if the game misbehaves. Your worlds, your creations and your account key are in that list too, and nothing there is ever deleted automatically except the downloaded caches.
